Back-translate a protein to DNA

Paste an amino acid sequence in one-letter code. Each residue is assigned one of its synonymous codons at random, so every run gives a different DNA sequence that encodes the same protein.

Codon usage weights are approximate E. coli K-12 frequencies per thousand codons. Random choices use the browser’s cryptographic random number generator. Check the output for unwanted restriction sites, repeats, or extreme GC content before ordering synthesis.
